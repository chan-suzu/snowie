# ❄ Snowie

**Снег на рабочем столе Windows.** Снежинки падают поверх всех окон и копятся сугробами на окнах и на панели задач. Из снега можно скатать снежок и запустить им в окно или слепить снеговика. Иногда проезжает снегоуборщик, а в новогоднюю полночь из коробки на панели задач стреляет салют.

Программа написана на Rust, рисует через Direct2D и DirectComposition, ресурсы видеокарты почти не нагружает и не мешает работать: все щелчки мимо снега проходят в окна как обычно.

## Возможности

| | |
|---|---|
| 🌨 **Снегопад** | Снежинки разного размера и глубины, их качает ветер. Плотность, размер и ветер настраиваются. |
| 🏔 **Сугробы** | Снег копится на верхних краях окон и на панели задач, осыпается по углу естественного откоса и свешивается с краёв окна. Части сугроба, закрытые другими окнами, не видны. |
| 🪟 **Живые окна** | Сугроб едет вместе с окном. Если потрясти окно, снег слетит; если закрыть или свернуть окно, сугроб осыпется вниз. |
| ⚪ **Снежки** | Возьмите снег мышкой, покрутите курсором по кругу, и комок скатается в шар. Если катать шар над сугробом, он растёт без ограничений, но чем он больше, тем тяжелее его тянуть. Брошенный шар разбивается об окно и оставляет на нём след. |
| ⛄ **Снеговик** | Положите три шара друг на друга (отпускайте их над сугробом, не бросая), и получится снеговик: шляпа, шарф, нос-морковка, руки-веточки. Сильным броском снеговика можно разбить. |
| 🚜 **Снегоуборщик** | Раз в N минут проезжает по панели задач и расчищает снег. Снеговиков объезжает. |
| 🎆 **Салют** | Коробка с фейерверками на панели задач показывает отсчёт до Нового года. В полночь 1 января начинается салют на три минуты с поздравлением. Можно добавить свои таймеры (каждый день в ЧЧ:ММ), а щелчок по коробке запускает салют сразу. |
| 🎵 **Музыка и звуки** | «Jingle Bells» и «We Wish You a Merry Christmas» в аранжировке для музыкальной шкатулки с бубенцами. Снег хрустит, когда его берёшь и катаешь; снежок свистит в полёте и шлёпается; у салюта и снегоуборщика свои звуки, со стереопанорамой по положению на экране. |
| ⚙ **Настройки** | Окно с настройками, значок в трее, автозапуск с Windows. В полноэкранных играх и видео снег прячется. |

## Установка

Скачайте `snowie.exe` со страницы [Releases](../../releases) и запустите. Программа не требует установки и прав администратора.

Или соберите сами (нужен Rust 1.95+):

```bash
cargo build --release
```

```bash
target/release/snowie.exe
```

## Управление

- **Левая кнопка на сугробе**: взять снег. Пока кнопка зажата, водите мышью по кругу: комок станет шаром.
- **Отпустить на ходу**: бросок. **Отпустить, остановив мышь**: шар просто упадёт и ляжет на сугроб.
- **Щелчок по шару или снеговику**: взять верхний шар.
- **Щелчок по коробке с салютом**: салют.
- **Значок в трее**: левая кнопка открывает настройки, правая — меню (пауза, музыка, сила снегопада, салют, снегоуборщик, «Убрать снег», выход).

Настройки хранятся в `%APPDATA%\Snowie\config.json`. Окно настроек открывается командой `snowie.exe --settings`.

## Музыка и лицензии

Код распространяется под лицензией [MIT](LICENSE).

Обе мелодии находятся в общественном достоянии: «Jingle Bells» (Джеймс Лорд Пьерпонт, 1857) и традиционный английский рождественский гимн «We Wish You a Merry Christmas». Записей и аудиофайлов в проекте нет: аранжировка задана нотами в [`src/music.rs`](src/music.rs) и синтезируется при запуске (музыкальная шкатулка, бас, бубенцы, лёгкая реверберация). Сохранить трек в WAV можно командой:

```bash
snowie.exe --export-music snowie.wav
```

Звуки тоже синтезируются при запуске: хруст снега собран из коротких зёрен фильтрованного шума, свист — из свипов синусоиды. Сохранить все звуки в папку можно командой:

```bash
snowie.exe --export-sounds sounds
```

## Как это устроено

```
src/
  main.rs      окно-оверлей, цикл кадров, трей и команды, музыка
  world.rs     симуляция: снежинки, сугробы, снежки, снеговики, снегоуборщик, расписание салюта
  render.rs    Direct2D → DXGI swap chain → DirectComposition (попиксельная прозрачность)
  fx.rs        фейерверки, часы и обратный отсчёт, данные снегоуборщика
  hook.rs      глобальный хук мыши: забирает щелчок, только если он попал в снег
  profiler.rs  профайлер: стадии кадра, GPU-таймер, ресурсы процесса, HUD, бенчмарк
  scan.rs      окна в порядке z-order, мониторы, полноэкранные приложения
  music.rs     синтезатор и ноты
  settings.rs  окно настроек (egui), запускается отдельным процессом
  config.rs    настройки и канал команд оверлею
```

- Окно-оверлей прозрачное для мыши (`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOREDIRECTIONBITMAP`) и висит поверх всех окон. Отрисовка идёт на видеокарте, около 60 кадров в секунду.
- Пока двигаются окна или летит снежок, кадры рисуются с частотой монитора. Позиции окон снимаются сразу перед отрисовкой (waitable swap chain, задержка в один кадр), а положение движущегося окна предсказывается по его скорости, поэтому сугроб не отстаёт.
- У каждого окна и у панели задач своя карта высот снега.
- Настройки открываются в отдельном процессе, чтобы сам оверлей оставался лёгким.

## Производительность

При обычном снегопаде на экране 3440×1440 кадр стоит около 0,5 мс CPU и 0,7 мс GPU, процесс занимает 3% одного ядра и 53 МБ памяти. Подробности, методика и история оптимизаций описаны в [docs/PERFORMANCE.md](docs/PERFORMANCE.md).

- **Профайлер на экране**: пункт «Профайлер» в трее или в настройках. Показывает время кадра по стадиям, время GPU, CPU процесса, память, видеопамять и график.
- **Бенчмарк**: `snowie.exe --bench 20 --out report.md`. Воспроизводимый прогон на настройках по умолчанию с отчётом avg/p50/p95/p99/max. Флаги: `--heavy`, `--fireworks`, `--fps 30`, `--music`.

## Отладка

| Переменная | Что делает |
|---|---|
| `SNOWIE_PRESNOW=1` | старт сразу с сугробами |
| `SNOWIE_NY_IN=20` | «Новый год» наступит через 20 секунд |
| `SNOWIE_LOG=1` | раз в секунду метрики профайлера пишутся в `%TEMP%\snowie-profile.csv` |

Иконку можно пересоздать командой `python scripts/make_icon.py`.
